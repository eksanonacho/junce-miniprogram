## 二、技术架构

### 前端
- **uni-app(Vue3)** — 一套代码编译出微信小程序 + H5。
- 状态管理 Pinia(存 token、用户信息)。
- 网络请求封装 uni.request(自动带 JWT token)。
- 前端由协作的同学负责(雇佣制),先做客户模块三个页面(填单/列表/详情)。

### 后端
- **NestJS(TypeScript)** — 模块化结构(每个业务一个 module:auth/customers/...)。
- 认证:JWT。
- 权限:RBAC(@Roles() 装饰器 + JwtAuthGuard + RolesGuard 双守卫)。

### 数据库
- **PostgreSQL 16**(本地库名 junce_dev)。
- ORM:**Prisma**(选 Prisma 而非 TypeORM,因对 AI 辅助开发更友好、migration 清晰、类型安全)。
- 金额字段统一 **Decimal(12,2)**。

### 权限体系
- 6 个角色:商务岗、业务岗、会计岗、部门主管、总务岗、管理员/老板。
- 角色用 PostgreSQL 原生 Enum 写死,杜绝脏数据。
- 双守卫:JwtAuthGuard 查"登录了吗"(否→401);RolesGuard 查"角色够吗"(否→403)。
- 接口加 `@Roles(RoleCode.XXX)` 即可限制访问角色。
- **硬规则**:涉及资金、合同、发票的接口,权限必须限制为总务 + 管理员。

### 部署方式
- Docker 容器化(Mac 上用 Colima 替代 Docker Desktop)。
- 两个项目共用同一台服务器,容器隔离运行。
- 服务器以君册名义注册,开发方代管。

### 代码位置
- 项目根目录:`/Users/a1234/cpp/junce-miniprogram/`
- 前端 `client/`,后端 `server/`。
- 需求文档:`junce_requirements_v2.md`;开发纪律:`CLAUDE.md`;开发日志:`.docs`。

## 四、为什么这样设计(关键决策记录)

- **金额统一 Decimal(12,2)**:这是财税系统,金额必须精确到分、禁止浮点误差。Prisma 默认 Decimal(65,30) 对钱无意义且浪费,已改为 12,2(支持亿级金额、2位小数)。已写入 CLAUDE.md。
- **RBAC 先做基础版**:客户尚未提供完整权限表,因此先实现"基础角色隔离"(登录 + 角色拦截),细粒度的"谁能看哪些数据"等权限表到货后再补。框架已留好扩展位置。
- **经营/工资看板一期只做"手动录入 + 自动汇总"**:全自动反推佣金/成本涉及复杂联动、易出错、需反复核对,风险高,放二期。一期由人手动录入数字,系统只做加减乘除、汇总、可视化。边界:系统只整理人填的数,不自己判断每笔钱该算给谁。
- **ownerId 从 JWT 获取,不让前端传**:防篡改。客户的"主理人"是当前登录的人,从 token 的 sub 读取,避免商务A把客户改成属于商务B。
- **客户分层(VIP/优质/中低/零申报)先 TODO**:客户尚未提供四档的界定标准,因此 tier 先做成可选字段、不做自动判断逻辑,标准到货后再补判断规则。
- **选 Prisma 而非 TypeORM**:AI 辅助开发对 Prisma 支持更好,migration 清晰,类型安全。
- **uni-app 一套代码**:客户要求"手机能用 + 老板看板",uni-app 一套代码出小程序 + H5,正好满足。
- **建群=手动**:客户已确认,公司自己在微信建群,系统不自动建群、不管群,只记录办件状态与材料归档(排除了企业微信深度开发的大坑)。

## 五、已踩过的坑(及解决方案)

| 问题 | 原因 | 解决方案 |
|---|---|---|
| Prisma 7 Adapter / ESM-CJS 冲突 | Prisma 7 默认生成 ESM 格式,NestJS 按 CommonJS 跑,启动报 `exports is not defined` | 在 schema.prisma 的 generator client 加 `moduleFormat = "cjs"`,清理 dist 和 generated 后重新 generate + build |
| 端口被占用 EADDRINUSE :3000 | 上一个后端进程没关干净,仍占着 3000 端口 | `lsof -ti:3000 \| xargs kill -9` 杀掉旧进程后重启 |
| localhost 请求返回 502 Bad Gateway | 本机开着代理/VPN,把 localhost 请求也劫持去走代理 | curl 加 `--noproxy "*"`,或代理软件开启"绕过本地地址",或临时关代理 |
| `python3 -m json.tool` 报 Expecting value | curl 多行命令被错误地拆分粘贴,或返回非 JSON | 一条完整命令整体粘贴;调试看原始返回可去掉 `\| python3 -m json.tool` |

> 经验:状态码速记 — 200成功 / 401没登录 / 403没权限 / 404找不到 / 500服务器错 / 502代理或网络问题(通常非代码问题)。
