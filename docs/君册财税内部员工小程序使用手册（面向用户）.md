# 君册财税内部员工小程序使用手册（面向用户）

> 适用对象：君册财税内部员工、客户验收人员  
> 版本：第一期验收版  
> 最后更新：2026-07-26  
> 本轮不验收：裂变业务。相关需求待进一步确认后另行补充。

---

## 一、系统用途

本系统用于把已成交客户从建档到日常维护的内部协作集中起来：

`客户建档 → 首次提单 → 岗位确认 → 办件 → 办结归档 → 代理户托管 → 会计日常维护`

同时提供收费、合同、发票、催收、主管任务、内部通知和管理看板。

企业微信群仍由员工手动建立，系统不自动建群。

> 2026-07-26 页面修正：代理户完成托管后，客户详情会正确展示托管记录、方案确认和会计接收状态。

## 三、完整业务流程

### 3.1 商务创建客户

商务进入“客户填单”，填写：

- 企业名称、客户分类
- 公司类型、行业、区域、注册日期、税务类型
- 年流水、人员数、客户分层

年流水不得为负数，最多两位小数，最大不超过 100 亿元。

创建成功后进入客户详情，继续完成：

1. 选择至少一项服务。
2. 阅读每项服务的材料、流程、时效，并点击“已阅读并确认”。
3. 配置业务岗、会计岗和总务岗。
4. 创建收费记录。

### 3.2 正式提交首次提单

客户详情中的“首次提单”会自动检查：

- 企业画像是否完整
- 是否选择服务
- 主理人是否阅读确认全部服务
- 是否配置业务岗、会计岗、总务岗
- 是否创建收费记录

有缺失项时，系统会逐项显示，不能正式提交。

资料完整后由客户主理人点击“正式提交提单”。提交后：

- 业务岗、会计岗、总务岗分别收到通知。
- 被指派员工进入客户详情，点击“确认岗位接单”。
- 同一员工兼任多个岗位时，一次确认本人全部岗位。
- 商务可以在首次提单卡片查看各岗位是否确认。

如果提交后又修改企业资料、服务、人员配置或收费记录，原提单会自动失效，岗位确认会清空，需要重新正式提交。

### 3.3 创建和办理办件

客户主理人、主管或管理员根据已选服务创建办件。

关键人员含义：

- 对接人：实际办理、办结和打卡归档的人。
- 回执接收人：接收办理结果，不负责操作该办件。

系统按照服务负责岗位选择对接人：

- 工商、开户、变更、资质等业务服务 → 业务岗
- 社保、公积金、代理记账、财务外包、合规等会计服务 → 会计岗
- 商务负责服务 → 客户主理人
- 主管、管理员可处理特殊情况

正常状态顺序：

`待办 → 办件中 → 办结 → 已打卡`

系统不允许跳级或倒退。操作步骤：

1. 对接人点击“开始办件”。
2. 实际办理完成后点击“办结”。
3. 上传至少一份办结电子材料。
4. 点击“确认打卡”完成归档。

回执接收人只能查看，不能代替对接人操作。

### 3.4 客户状态自动变化

- 任一办件开始后，客户进入“办件中”。
- 全部服务都完成打卡归档后，客户进入“办结”。
- 代理户完成托管会计确认后，客户进入“维护中”。
- “出库”是人工终态，系统不会自动重新激活。

### 3.5 代理户托管

只有代理户可以进入托管，且顺序被系统强制控制：

`全部办件打卡归档 → 填写企业概况和服务方案 → 主理人确认 → 主管分派会计 → 被分派会计确认 → 日常维护`

具体操作：

1. 全部服务办结打卡后，会计、主管或管理员创建托管入档。
2. 创建时必须填写企业概况和服务方案。
3. 客户主理人收到通知并确认服务方案。
4. 方案确认后，主管或管理员才能分派会计。
5. 被分派会计收到通知并确认接收。
6. 系统将代理户状态更新为“维护中”。

限制：

- 办件未全部归档时不能创建托管。
- 方案未确认时不能分派会计。
- 方案确认后不能再修改企业概况或服务方案。
- 会计确认接收后不能重新分派。

### 3.6 会计日常维护

会计工作台的“日常登记”支持：

- 客户入库
- 客户出库
- 开票登记
- 日常咨询
- 账务进度
- 社保明细
- 报税进度
- 年报进度
- 其他

会计只能为本人负责的客户登记。填写客户、类型、日期、工作内容和备注后保存，状态为“已登记”。

主管会收到待复核提醒，在“会计台账复核”中点击“确认复核”。复核后状态为“已复核”，会计不能再修改。

信息查看范围：

- 商务查看本人主理客户。
- 业务查看本人关联客户。
- 会计查看本人记录。
- 主管、总务、管理员查看全部。

### 3.7 主管任务

主管或管理员可以创建任务、指定接收人、关联客户、填写内容和截止时间。

任务接收人按顺序操作：

`待确认 → 进行中 → 已完成`

主管查看进度；管理员可以应急处理。普通员工不能确认或完成别人的任务。

### 3.8 收费、合同、发票和催收

商务可以为本人客户创建收费记录，总务或管理员可以维护和确认。

当前支持：

- 一次性、定金加尾款两种收费方式标记
- 应收总金额
- 合同号、发票号
- 未收/已收状态
- 总务发起催收
- 收费确认和催收通知

规则：

- 一个客户一期只保留一条收费记录。
- 只有总务或管理员能确认已收和发起催收。
- 已确认收款后不能修改收费方式或金额。
- 合同号、发票号仍可由总务或管理员补充。
- “定金加尾款”当前记录总金额和最终收款状态，不拆分两次到账明细。

### 3.9 消息中心

消息中心会接收：

- 首次提单和岗位接单
- 新办件及办件进度
- 主管任务
- 收费确认和催收
- 托管方案、会计分派及接收
- 会计台账待复核和复核结果

点击通知会进入相应客户、办件、任务、收费、托管或会计台账页面。支持单条已读和全部已读。

### 3.10 管理看板

主管和管理员可以查看：

- 客户：总数、分类、分层、生命周期
- 服务：服务项和办件状态
- 任务：各状态数量和逾期数量
- 收费：已收、未收、金额和催收次数
- 会计服务：本月登记、待复核、已复核和登记类型

总务另有经营数据和工资数据手动录入页面。第一期不自动计算佣金、工资或绩效。

## 四、人工验收步骤

建议使用一个全新的代理户测试，避免旧数据影响判断。

### 4.1 商务验收

1. 使用 `shangwu` 登录。
2. 创建代理户，完整填写企业画像。
3. 选择服务并逐项确认阅读。
4. 配置业务、会计、总务。
5. 创建收费记录。
6. 查看首次提单缺失项应全部消失。
7. 正式提交提单。
8. 确认不能查看或操作其他商务的客户。

预期：提交成功，各岗位变为待确认并收到通知。

### 4.2 业务验收

1. 使用 `yewu` 登录。
2. 在消息中心打开新客户提单并确认岗位接单。
3. 打开分配给本人的业务办件。
4. 依次开始办件、办结、上传材料、打卡。
5. 尝试操作自己只是回执接收人的办件。

预期：本人对接办件可完成全流程；回执接收办件不能操作。

### 4.3 会计验收

1. 使用 `kuaiji` 登录并确认岗位接单。
2. 如存在会计类办件，完成开始、办结、归档打卡。
3. 在托管会计分派后确认接收。
4. 进入“日常登记”，新增报税或账务记录。
5. 复核前编辑一次该记录。

预期：只能看到本人负责客户；记录保存后主管收到提醒。

### 4.4 主管验收

1. 使用 `zhuguan` 登录。
2. 尝试在托管方案未确认时分派会计。
3. 方案确认后正常分派。
4. 创建任务并指定会计。
5. 打开“会计台账复核”，复核会计刚才的记录。
6. 打开数据看板，查看会计服务统计。

预期：未确认方案不能分派；复核成功；看板待复核数量相应减少。

### 4.5 总务验收

1. 使用 `zongwu` 登录并确认首次提单岗位。
2. 打开收费记录，补充合同号和发票号。
3. 未收状态发起催收。
4. 确认已收。
5. 确认已收后尝试修改金额。
6. 查看会计服务台账、经营数据和工资数据入口。

预期：催收和确认成功；已收后金额不能修改；无关角色不能查看收费催收明细。

### 4.6 管理员验收

1. 使用 `admin` 登录。
2. 查看客户、办件、任务、收费、会计服务看板。
3. 检查消息中心单条已读和全部已读。
4. 查看各角色操作后的最终客户状态。

预期：全部数据可查看；代理户在会计确认托管后为“维护中”。

### 4.7 再次验证提单失效

1. 回到已正式提交的客户。
2. 修改企业资料、服务、人员配置或收费记录中的任一项。
3. 再次查看“首次提单”。

预期：正式提交状态失效，岗位确认清空，需要重新提交。

## 六、常见问题

- “无权限”：确认当前账号角色、客户归属、人员配置以及自己是否为实际对接人。
- 无法正式提交：查看首次提单卡片中的缺失项。
- 找不到办件对接人：先为客户配置对应业务岗或会计岗。
- 无法创建托管：确认该客户是代理户，且全部办件已经打卡归档。
- 无法分派会计：先让客户主理人确认服务方案。
- 会计找不到客户：确认该会计已配置为客户会计岗或托管分派会计。
- 会计记录不能修改：该记录已经复核，需要联系主管或管理员。
- 已收金额不能修改：这是收款数据保护；如数据确实错误，应由管理员核查处理。
- 页面加载失败：确认前后端服务正常，再刷新或重新登录。
- 登录过期：重新登录。

不要在公开群聊发送真实客户密码、合同、发票或其他敏感资料。
